
# Tehran Metro Navigator

An interactive Tehran Metro route planner built with Next.js.

## Features

- Explore Tehran Metro stations and lines
- Find routes between stations
- Discover nearby metro stations
- Visualize selected routes on an interactive map
- Animated train movement along the selected route

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- Metto API

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
